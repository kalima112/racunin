# RACUNIN — Starter Website

## Cara pakai
1. Buka `index.html` untuk preview.
2. Cari semua `https://shopee.co.id/` lalu ganti dengan link Shopee Affiliate produk yang sebenarnya.
3. Ganti nama produk, harga, kategori, emoji, dan artikel sesuai produk yang kamu pilih.
4. Upload folder ini ke Cloudflare Pages, Netlify, atau GitHub Pages.

## SEO
Versi awal sudah memiliki title, meta description, canonical, struktur heading, URL root sederhana, dan konten yang bisa dikembangkan.
Untuk ranking Google, tambahkan artikel yang benar-benar membantu pengguna, internal linking, Search Console, sitemap.xml, dan halaman produk/kategori yang unik.

## Catatan affiliate
Gunakan disclosure affiliate yang jelas dan patuhi syarat/program Shopee Affiliate yang berlaku.
